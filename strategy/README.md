# OIH futures-curve timing (main strategy)

| File | What it is |
|---|---|
| `PREREG_curve.md` | The plan, written 2026-11-15 before any return test: hypotheses, the 12 combinations, the selection rule, the backtest rule and the pass mark. |
| `curve_is.py` | Build period (2021-11-01 to 2024-12-31). Cuts all data at 2024-12-31, then runs the 12 predictive regressions and the same-day check of what energy stocks track. Writes `data/curve_is_grid.csv`. |
| `curve_oos.py` | Runs the frozen rule once on the test period (2025-01-01 to 2026-10-30), then robustness checks that were added afterwards and labelled as such. Writes `data/curve_backtest.csv` (daily strategy return, position, score, OIH return). |
| `PREREG_history.md`, `curve_history.py` | The same frozen rule on 2001-02-26 to 2021-10-29 using EIA month-1 / month-4 prices. Failed (t = -0.71). |
| `deck_numbers.py` | Figures in the deck that the scripts above don't print: average position, the two example weeks, the 0.84 match with EIA data, and returns by year split into long and short sides. |
| `RESULTS.md` | Full results, audit and caveats for all of the above. |

## Data (`data/`)

| File | Source | Dates |
|---|---|---|
| `prices.csv` | Hackathon dataset (Yahoo adjusted close, 14 assets + VIX) | 2021-11-01 to 2026-10-30 |
| `cl_front_z27.csv` | Yahoo `CL=F` (next-month WTI) and `CLZ27.NYM` (Dec-2027 WTI) | 2021-01 to 2026-10 |
| `curve_etfs.csv` | Yahoo USO and USL (adjusted) | 2021-09 to 2026-10 |
| `eia/RCLC1-4.xls`, `curve_eia.csv` | EIA NYMEX WTI contracts 1-4 | 1985 to 2024-04-05 |
| `oih_hist.csv` | Yahoo OIH (adjusted), for the history test | 2001 onward |

Generated by the scripts: `curve_is_grid.csv`, `curve_backtest.csv`, `curve_history_backtest.csv`, `deck_weekly.csv` (weekly points for the deck chart). `curve_history_output.txt` is the saved printout of the history test.

## Things to know before presenting

- Most of the profit came from the long side (2023, 2025). The short side was about break-even overall and lost money in the 2026 supply shock, when OIH rose 44% (`deck_numbers.py`, part 4).
- In the Build column, our numbers start 2022-11 (when the score first exists) but OIH's start 2021-11.
- "Extra return" is alpha: return beyond our OIH exposure, not our return minus OIH's.
- The best Build result (t = -2.49) met our selection rule but not the stricter 2.87 bar for testing 12 combinations.
- Sharpe uses a 0% risk-free rate and cash earns 0%.
